# PRODIGY_DS_01

## Overview
Visualized the distribution of categorical and continuous demographic variables (gender counts and age distributions) using a self-contained Python workflow in Google Colab.

## Contents
* `task_01.ipynb` — Executable notebook containing synthetic data generation, exploratory analysis, and visual outputs.

## Key Insights
* **Gender Distribution**: Balanced demographic representation across the simulated cohort (~49% female, ~49% male, ~2% non-binary).
* **Age Distribution**: Normal-like spread centered around a working-age median (~30 years) with natural tapering in older age brackets.

## Tech Stack
* Python (Pandas, NumPy, Seaborn, Matplotlib)
* Google Colab
